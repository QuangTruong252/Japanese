# SPEC-03 Màn Học (`/hoc`, `/hoc/[so]`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Triển khai màn Học theo `docs/specs/SPEC-03-man-hoc.md`: lưới 25 bài N5 tại `/hoc` và trang chi tiết một bài tại `/hoc/[so]` (Từ vựng → Ngữ pháp), có thanh tiến độ sống đọc từ Dexie, nút phát âm Web Speech, và neo `#vocab-<id>` / `#grammar-<id>` cho SPEC-13.

**Architecture:** Cả hai route là Server Component tĩnh hoá lúc build (`generateStaticParams` cho 25 bài). Dữ liệu bài học nạp trên server qua `loadLessonSummaries()` / `loadLessonData()` đã có trong `web/src/lib/lessons.ts` — trình duyệt chỉ nhận RSC payload, không kéo 50 file JSON. Phần động (tiến độ Dexie, phát âm) tách thành ba client island nhỏ: `LessonGrid`, `LessonProgress`, `SpeakButton`.

**Tech Stack:** Next.js 16.3.5 (App Router), React 19, TypeScript strict, Tailwind CSS v4, Dexie 4 + `dexie-react-hooks`, Base UI (`@base-ui/react`) qua shadcn `base-nova`, Lucide React, `node:test`.

## Global Constraints

Bốn ràng buộc chốt từ vòng rà soát — mọi task phải giữ:

1. **`/hoc/[so]` `notFound()` khi `so` không phải số hợp lệ 1..25.** `/hoc/tra-cuu` (SPEC-12) và mọi đường dẫn lạ không được rơi vào trang chi tiết rồi crash.
2. **Neo bắt buộc:** mỗi mục từ vựng có `id="vocab-<w.id>"`, mỗi khối ngữ pháp có `id="grammar-<point.id>"` (slug trong JSON: `vocab-watashi`, `grammar-wa-desu`), kèm `scroll-mt-24` để không dính dưới nav. SPEC-13 §2.4 sinh link đúng dạng này.
3. **Thanh tiến độ là "Đã học n/m"**, n = số `reviewItems` có `targetId` khớp `vocab-<XX>-`, m = số từ của bài. **Không bao giờ dùng chữ "đã thuộc".** Đọc bài không tạo `reviewItems` nên bài mới đọc xong vẫn là 0 — đúng thiết kế, hiển thị "Chưa học".
4. **Bài `unverified` học bình thường**, chỉ thêm một dòng muted cuối trang. **Không render dòng nguồn sách khi `sourceRef` vắng** — cả 25 bài hiện đều thiếu `sourceRef`.

Ràng buộc chung của repo:

- Không hardcode mã màu; chỉ dùng token Washi (`bg-card`, `text-muted-foreground`, `bg-verb-1`, ...).
- Mọi chữ tiếng Nhật bọc trong class `jp`; furigana chỉ qua component `Furigana` — **không** viết parser/regex mới trong component.
- Vùng chạm nút ≥ 48×48px; nút phát âm dùng `size="quiz"` + `className="w-12 px-0"` (không thêm size mới vào `button.tsx`).
- TTS **luôn đọc `kana` hoặc `stripFurigana(...)`**, không bao giờ đọc chuỗi thô `私[わたし]`; `aria-label` cũng vậy.
- Class `translation` (Study Mode làm mờ) chỉ gắn lên **nghĩa từ vựng** và **bản dịch câu ví dụ**. **Không** gắn lên `explanation.vi` (làm mờ phần giải thích thì trang thành vô dụng) và **không** gắn lên `pattern.vi` (trường này chứa tiếng Nhật `N1 は N2 です` → dùng `jp`).
- Không thêm dependency. Không sửa `globals.css`, `layout.tsx`, `AppNav.tsx`, `button.tsx`, `Furigana.tsx`.

```typescript
/**
 * Đếm số mục từ vựng đã VÀO LỊCH ÔN theo bài (SPEC-03 §4) — "đã học", không phải "đã thuộc".
 * Đầu vào là mảng primary key của `reviewItems`; hàm thuần, không đọc Dexie.
 */
export function countLearnedByLesson(targetIds: string[]): Map<number, number> {
  const counts = new Map<number, number>();
  for (const id of targetIds) {
    const m = /^vocab-(\d{2})-\d{2}$/.exec(id);
    if (!m) continue;
    const lesson = Number(m[1]);
    counts.set(lesson, (counts.get(lesson) ?? 0) + 1);
  }
  return counts;
}
```

- [x] **Step 1: Tạo `web/src/components/SpeakButton.tsx`**

```tsx
'use client';

import { useEffect, useState } from 'react';
import { Loader2, Volume2 } from 'lucide-react';
import { Button } from '@/components/ui/button';
import { hasJapaneseVoice, speak } from '@/lib/tts';

/**
 * Nút phát âm. `text` là chuỗi ĐỌC ĐƯỢC (kana hoặc đã stripFurigana), không phải notation thô.
 * Không có giọng ja-JP thì ẩn hẳn nút (SPEC-03 §5) — nút chết tệ hơn không có nút.
 */
export function SpeakButton({ text, label }: { text: string; label: string }) {
  const [hasVoice, setHasVoice] = useState(false);
  const [speaking, setSpeaking] = useState(false);

  useEffect(() => {
    let alive = true;
    hasJapaneseVoice().then((ok) => {
      if (alive) setHasVoice(ok);
    });
    return () => {
      alive = false;
    };
  }, []);

  if (!hasVoice) return null;

  const handleClick = () => {
    const utterance = speak(text);
    if (!utterance) return;
    setSpeaking(true);
    const done = () => setSpeaking(false);
    utterance.addEventListener('end', done);
    utterance.addEventListener('error', done);
  };

  return (
    <Button
      type="button"
      variant="ghost"
      size="quiz"
      className="w-12 px-0"
      aria-label={`Phát âm ${label}`}
      onClick={handleClick}
    >
      {speaking ? <Loader2 className="motion-safe:animate-spin" /> : <Volume2 />}
    </Button>
  );
}
```

`size="quiz"` cho `h-12`, `w-12 px-0` cho đủ 48×48px. Hai icon cùng `size-5` nên bề rộng nút không đổi giữa hai trạng thái. `motion-safe:` tắt xoay khi `prefers-reduced-motion: reduce`.

```tsx
'use client';

import { useLiveQuery } from 'dexie-react-hooks';
import { db } from '@/lib/db';
import { Progress } from '@/components/ui/progress';

/** Thanh tiến độ thuần — lưới /hoc đã có sẵn số, không query lại (SPEC-03 §4). */
export function ProgressBar({ learned, total }: { learned: number; total: number }) {
  return (
    <Progress
      value={learned}
      max={Math.max(total, 1)}
      getAriaValueText={() => `${learned} trên ${total} từ đã vào lịch ôn`}
      className="flex-col items-start gap-1.5"
    >
      <span className="text-xs text-muted-foreground tabular-nums">
        {learned === 0 ? 'Chưa học' : `Đã học ${learned}/${total}`}
      </span>
    </Progress>
  );
}

/** Tiến độ một bài cho trang chi tiết. Đọc bài không tạo reviewItems — 0 là đúng. */
export function LessonProgress({ lesson, total }: { lesson: number; total: number }) {
  const prefix = `vocab-${String(lesson).padStart(2, '0')}-`;
  const learned = useLiveQuery(
    () => db.reviewItems.where('targetId').startsWith(prefix).count(),
    [prefix],
    0
  );
  return <ProgressBar learned={learned} total={total} />;
}
```

`targetId` là primary key (`db.ts`) nên `startsWith` chạy trên index, không quét bảng. `Progress` của Base UI đã tự dựng `ProgressTrack` (`h-1` = thanh 4px) + `ProgressIndicator`, và tự đặt `role="progressbar"` + `aria-valuenow`.

```tsx
'use client';

import Link from 'next/link';
import { useLiveQuery } from 'dexie-react-hooks';
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from '@/components/ui/card';
import { ProgressBar } from '@/components/LessonProgress';
import { db } from '@/lib/db';
import { countLearnedByLesson } from '@/lib/stats';
import type { LessonSummary } from '@/lib/lessons';

export function LessonGrid({ summaries }: { summaries: LessonSummary[] }) {
  // MỘT query cho cả lưới, không phải 25 subscription. targetId là primary key nên
  // startsWith chạy trên index; primaryKeys() không kéo fsrsCard về.
  const targetIds = useLiveQuery(
    () => db.reviewItems.where('targetId').startsWith('vocab-').primaryKeys(),
    [],
    [] as string[]
  );
  const learnedByLesson = countLearnedByLesson(targetIds);

  return (
    <div className="grid grid-cols-1 gap-4 md:grid-cols-2">
      {summaries.map((s) => (
        <Link key={s.number} href={`/hoc/${s.number}`} className="rounded-xl focus-visible:ring-[3px] focus-visible:ring-ring/50 focus-visible:outline-none">
          <Card className="h-full transition-colors hover:bg-muted/40">
            <CardHeader>
              <CardTitle>Bài {s.number} — {s.title.vi}</CardTitle>
              <CardDescription>{s.description.vi}</CardDescription>
            </CardHeader>
            <CardContent className="space-y-2">
              <p className="text-xs text-muted-foreground">
                {s.vocabCount} từ · {s.grammarCount} mẫu ngữ pháp
              </p>
              <ProgressBar learned={learnedByLesson.get(s.number) ?? 0} total={s.vocabCount} />
            </CardContent>
          </Card>
        </Link>
      ))}
    </div>
  );
}
```
