# Kế hoạch triển khai SPEC-12 — Tra cứu: Kanji, Động từ & 10 Bảng tham chiếu

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Xây dựng hệ thống màn hình tra cứu học tập toàn diện gồm Trung tâm Tra cứu (`/hoc/tra-cuu`), Lưới và Chi tiết 169 chữ Kanji (`/hoc/tra-cuu/kanji`), Bảng 156 Động từ 5 thể (`/hoc/tra-cuu/dong-tu`), và 10 Bảng tham chiếu ngữ pháp (`/hoc/tra-cuu/bang/[slug]`) theo đúng đặc tả SPEC-12 và bộ mockup từ `mock/22-tra-cuu.png` đến `mock/26-bang-tham-chieu.png`.

**Architecture:**
- Mô-đun dữ liệu thuần `src/lib/lookup.ts` kiểm thử 100% bằng unit tests: quản lý nạp 169 chữ Kanji, 156 động từ, 10 bảng tham chiếu, dựng chỉ mục tra ngược Kanji ↔ Từ vựng runtime từ 25 bài, hàm lọc và phát hiện ví dụ chưa xác minh.
- Phân tách Server Components và Client Components: Server Components chịu trách nhiệm SSG `generateStaticParams` và nạp dữ liệu gốc; Client Components đảm nhiệm tương tác lọc, tìm kiếm `?q=`, kết nối IndexedDB `useLiveQuery` để đánh dấu "Đã học".
- UI theo hệ thiết kế Washi: chuẩn token semantic, hỗ trợ Dark mode, bảng HTML chuẩn truy cập và tối ưu hiển thị mobile 390px với cột ghim cố định.

**Tech Stack:** Next.js 16 (App Router), React 19, TypeScript, Dexie 4 (`dexie-react-hooks`), Lucide React, Base UI / Tailwind CSS 4.

---

## Global Constraints

- **Trung thực dữ liệu (SPEC-12 §2.1):** 431/907 ví dụ Kanji có `vi === en` phải hiển thị nhãn "Chưa xác minh", tuyệt đối không hiển thị tiếng Anh giả làm tiếng Việt.
- **Không vỡ layout 8 ô header rỗng (SPEC-12 §3.5):** Giữ nguyên ô trống trong bảng tham chiếu, không điền ký tự giả.
- **An toàn định tuyến (SPEC-12 §2.3):** Route con `/hoc/tra-cuu` không bị xung đột với `/hoc/[so]`.
- **Cột ghim cố định (SPEC-12 §3.4):** Bảng động từ trên mobile cuộn ngang với cột đầu tiên ghim cố định (`sticky left-0`).
- **Không hardcode màu sắc:** Sử dụng token Washi (`bg-card`, `border-border`, `--verb-1`, `--verb-2`, `--verb-3`).

  export function buildKanjiVocabIndex(vocabByLesson: Array<{ lesson: number; words: Array<{ id: string; word: string; kana: string; meaning: { vi: string; en?: string } }> }>): Map<string, VocabRef[]>;
